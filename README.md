# Gestão Financeira em Python

Um sistema simples de controle financeiro pessoal executado no terminal. Ele permite registrar despesas e receitas, salvando os dados automaticamente de forma persistente.

**Funcionalidades:**
* Registra novas transações contendo descrição, valor e categoria.
* Salva o histórico automaticamente em um arquivo `dados_financeiros.json`.
* Calcula e exibe o resumo do saldo acumulado por categoria.

**Como executar no seu computador:**
1. Certifique-se de ter o Python instalado.
2. Baixe o arquivo `gestor_financeiro.py`.
3. Abra o Prompt de Comando ou Terminal na pasta onde o arquivo foi salvo.
4. Execute o comando: `python gestor_financeiro.py`

**Tecnologias utilizadas:**
* Python (Lógica de programação e Orientação a Objetos)
* Biblioteca `json` nativa (Persistência e leitura de dados)
